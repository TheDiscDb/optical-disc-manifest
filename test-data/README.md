# Test data policy

This directory may contain only small optical-disc metadata fixtures needed for
conformance, such as IFO, MPLS, CLPI, and BDMV XML.

Every fixture must include provenance, redistribution permission or license,
format, purpose, SHA-256 digest, and expected parsed result. Do not commit VOB,
M2TS, ripped media, decryption keys, or metadata of uncertain provenance.
